# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-12-18

### Added
- Core HTTP request functionality (GET, POST, PUT, DELETE, etc.).
- Collections for organizing requests into folders.
- History view for tracking previous requests.
- Environment variables support with `{{variable}}` syntax.
- Authentication support: Bearer Token, Basic Auth, and API Key.
- Two-pane and single-pane layout modes.
- JSON response formatting and syntax highlighting.
- Native VS Code UX integration.
