This page highlights recent releases. The canonical full changelog lives in the repository at [`CHANGELOG.md`](https://github.com/liteclienthq/liteclient/blob/main/CHANGELOG.md).

## 0.16.0

- Added pre-request and post-response scripting
- Added a dedicated tests tab for script results
- Added script persistence through Postman import and export

## 0.15.0

- Added response formatting improvements for JSON, HTML, and XML
- Added a manual format action in the response toolbar

## 0.14.0

- Added the environment manager panel
- Added current-value overrides for environment variables
- Added secret-variable masking and related variable actions

For the full release history, including older versions and detailed entries, see [`CHANGELOG.md`](https://github.com/liteclienthq/liteclient/blob/main/CHANGELOG.md).
